# NTCG · Linux 联机测试版

面向 Ubuntu 24.04，支持部署后通过浏览器与朋友联机游玩。

## 部署

部署方案、安装步骤和排障见 [Ubuntu 部署说明](docs/ubuntu-24.md)。实际地址、连接凭证和运行目录由服务器维护者在本地保管。

## 游玩

1. 输入昵称进入游戏，自动加入 SD01「罗德岛」与 SD02「炎－龙门」两套预组，各 50 张主卡＋3 张基地。大厅下拉框和卡组编辑器都可以选择。
2. 选择「自定义对战模式」，一人创建房间，把房间码告诉朋友。
3. 另一人加入，双方准备，房主开始，猜拳决定先攻。
4. 与单人练习一样，点击手牌打开「部署／使用／设置／精英化」小菜单，再点击战场上发光的位置；点击己方干员选择「攻击」，然后点击发光的敌方目标。效果从手牌或战场直接选择，翻牌、回收与排序使用卡面窗口。

「单人练习」为浏览器中的测试 AI。

罗德岛沿用原有默认配表；龙门原先只有卡池，本轮按现有卡牌补齐测试预组：基础陈与诗怀雅各 3 张、精英化各 2 张，其余各 4 张。配表在 `data/starter-decks.json` 中统一维护。旧存档会补齐缺少的预组，不重复添加；编辑预组后保留为自定义卡组，下次加载时另补回原版，已有出战选择不会被覆盖。

## 当前范围

两套卡池现有的 **28 张主卡＋6 张基地** 均已接入服务器规则：部署触发、查看/翻开/排序、持续增益、墓地回收、每回合次数、叠放精英化、战斗保护、战术和四种陷阱响应。具体支持与采用的结算约定见 [联机效果说明](docs/online-effects.md)。

服务器在 `engine/rules.js` 中结算，客户端只提交意图和选择。需要选择时暂停结算，按接收者发送可见选项；刷新后恢复同一个选择。非法、过期及越权选择不修改状态。单机旧效果代码仍保留，本轮没有把两个运行模式统一为同一个引擎。

当前使用昵称，没有正式账户。卡组和录像保存在浏览器；对局保存在服务器内存，重启/更新会中断现有对局。两端都断线且对局无活动 15 分钟后回收，其他对局最长保留到连续 6 小时无操作。IP 方案使用 HTTP，仅用于无密码的朋友内测；后续需要正式账号时应配置 HTTPS。

## 卡牌与卡图导入

双击项目根目录 `启动卡牌工坊.cmd`，使用本地表单编辑卡牌、批量导入 JSON、批量匹配卡图和预览。默认地址 `http://127.0.0.1:3210`，保存自动备份，只修改本地项目。完整操作见 [卡牌工坊说明](docs/card-manager.md)。

新效果不会仅凭文字自动实现；待接入卡会禁止用于联机。导入后仍需测试、同步 GitHub并单独更新服务器。

## 本地开发与检查

使用 Node.js 24 或更高版本：

```bash
cd rhodes-pvp-v98
npm ci --ignore-scripts
npm test
npm start
```

服务端与网页仍位于 `rhodes-pvp-v98/`，此轮保留既有目录以减少与上游冲突。根目录旧的 `rhodes-pvp-v98-final.zip` 是历史原始产物，**部署必须使用源码目录，不使用这个旧 ZIP**。

测试包含卡池校验、25 段客户端内联脚本及外部模块语法检查、41 个效果场景、联机小菜单/战场目标/费用/排序/取消/错误恢复/单机隔离检查、卡牌工坊导入/回滚/本机接口检查，以及真实 HTTP/WebSocket 双连接开局与重连流程。CI 在 Ubuntu 24.04 上运行这些检查并构建镜像。
