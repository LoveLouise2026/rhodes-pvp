# 两套卡池的联机效果

本轮接入范围为当前 JSON 卡池中全部 28 张主卡和 6 张基地，不包含尚未设计的新卡或泛用脚本语言。数据文件仍负责卡面，`engine/rules.js` 明确实现结算；以后只改卡面文字不会自动改变规则。

## 如何操作

双方调度后沿用单人交互。点击手牌，在原来的小菜单中选择「部署／使用／设置／精英化」，再点击发光的合法位置或同名基础干员。点击己方战场干员选择「攻击」，再点击发光的敌方干员或基地生命。菜单和目标范围来自服务器合法动作，不在本地改动规则状态。取消按钮或 Esc 可撤销尚未提交的操作。

夜刀展示、巡林者效果部署、费用选择、陷阱响应和战场效果目标直接在发光的手牌／位置／干员上点击。单项选择点击即提交，多张费用要选齐后确认；基地升级必须选两张或不发动。查看牌库、墓地回收、特殊精英化和同时效果排序使用与单人相近的卡面窗口，悬停可看详情，多项选择按点击顺序显示编号。排序必须选齐全部选项。选择期间不能结束回合或进行其他规则动作；可点「查看战场」暂时隐藏卡面窗口，再点「继续选择」恢复。

墓地德克萨斯从原来的弃牌区查看窗口发动；罗德岛 Lv3 基地点击基地卡后确认发动。满足条件的区域会发光提示。结算记录进入左侧「出牌记录」。投降沿用战场原有入口，选择期间也可以放弃对局。

## 结算约定

以下沿用现有单机代码可确认的约定；规则文档未正式定义的细节应由玩法设计师在此基础上确认：

- 每次普通部署、精英化、通常战术、盖放各占用一次普通出牌；基地等级决定出牌次数及普通打牌等级上限。效果部署、特殊精英化不占普通次数，可以越过普通等级限制。普通部署仅限基础干员。
- 精英化继承原干员的入场、攻击及实体记录；被击败或弹回时整叠一并移动。煌的保护只防战斗击败，不防效果移除。
- 同时点效果先处理当前回合玩家，再处理对手；同一玩家的多个效果可选择顺序。处决模式升级及准备作战后续精英化先于其本次部署的触发。
- 陷阱只可盖在空后排，同一个位置不能同时有干员和陷阱；至少经过一次回合切换才可响应。仅在指定时点、专属条件满足时提供发动选择，选择不发动不消耗陷阱。
- 攻击宣言消耗次数，然后给对手陷阱窗口。响应结束重新验证攻击者实体和原目标。原目标离场、强制目标变化或直击路径被填入守方干员时，此次攻击结束，不自动改目标。攻击者离场或攻击无效后不再询问其他攻击陷阱。
- 多名陈的赤霄·绝影门槛取最高战斗力，沿用单机现有实现。普通近战在前排无人时攻击后排不算“绕过前排”，不扣杜宾/诗怀雅的远程修正。
- 基地生命翻出的干员不是场上干员，不吃场上增益，不触发场上干员被击败的效果；当前卡池没有带【触发】标记的基地生命战术。基地生命耗尽后再次合法直击才败北。
- 私密查看、排序、煌私密取牌只对本人发送选项及身份日志；翻开、展示、公开回收与已用战术会公开。对手只知道正在等待选择，不能读取选项或服务器续接任务。
- 无牌可抽时沿用原版的“抽取实际可用张数”，没有自行添加抽空判负。服务器重启恢复与选择超时判罚不在本轮范围。

## 验证

`npm test` 包含：41 个效果场景、8 个固定种子的自动对局模拟（每局最多 450 个操作/选择），逐步检查主卡实体守恒、陷阱/干员格子互斥；网络身份与 revision 检查；选择越权/重复回复/重连；交互小菜单、双方位置映射、费用/排序/取消、快速重复点击、失败恢复及单机隔离；卡池及脚本检查；真实 HTTP/WebSocket 开局流程。

浏览器人工验证使用罗德岛对龙门：开局调度、夜刀部署、本人效果弹窗、对手等待、选择中刷新后恢复、展示并抽牌。修复了测试中发现的调度监听器接管、刷新恢复停在登录页、重复初始化动画及卡组标签插入异常。

全部效果的组合并未逐一在浏览器人工演练；卡牌文本、单机实现与此处约定存在争议时，需修改规则规范及相应测试后再调整实现。当前仍是朋友间联机测试版。
